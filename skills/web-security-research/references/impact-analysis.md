# Impact Analysis

For every confirmed security weakness determine:

WHO is affected?

WHAT resource is affected?

WHAT can the attacker control?

WHAT privilege is obtained?

WHAT data becomes accessible?

WHAT security boundary is crossed?

CAN another controlled account be affected?

CAN administrative functionality be affected?

CAN server-side security boundaries be affected?

Distinguish:

Observed
Demonstrated
Inferred
Theoretical

Severity must be based on evidence rather than speculation.
