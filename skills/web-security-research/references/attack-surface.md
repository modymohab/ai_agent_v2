# Attack Surface Mapping

Map the application without assuming that URL names reveal security
importance.

Identify:

- pages
- APIs
- HTTP methods
- parameters
- identifiers
- authentication mechanisms
- state-changing operations
- account-management functionality
- administrative functionality

Classify functionality as:

- authentication
- account
- security
- data
- file
- administration
- privilege
- business logic
- other

Prioritize security-sensitive functionality for deeper review.
