# API Security Research

Map:

- endpoints
- methods
- parameters
- identifiers
- authentication
- authorization
- state changes

Pay particular attention to:

- account APIs
- security APIs
- administrative APIs
- data modification APIs
- deletion APIs
- file APIs

For every sensitive API operation determine:

- current identity
- resource owner
- expected role
- expected authorization
- actual result

A successful HTTP response is not sufficient evidence of a vulnerability.
