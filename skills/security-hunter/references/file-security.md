# File Security Hunting

## Focus
- file upload
- file download
- file access
- filename handling
- path handling
- content-type validation
- storage access controls

## Signals
- user-controlled filenames
- downloadable private objects
- inconsistent validation
- server-side processing of uploaded content

## Evidence
Record endpoint, file metadata, authorization state, and resulting behavior.

## Safety
Use harmless test files and authorized accounts.
