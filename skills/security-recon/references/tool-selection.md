# Tool Selection

## Principle
Choose the smallest authorized toolset that answers the current research question.

## Selection Factors
- scope
- request volume
- authentication requirements
- discovery goal
- evidence quality
- safety

## Prefer
- passive discovery before active discovery
- browser observation before broad automation
- targeted validation before repeated requests

## Prohibited Approach
Do not bypass rate limits, access controls, WAFs, or program safeguards merely to increase coverage.
