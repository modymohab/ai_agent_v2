# Endpoint Discovery

## Purpose
Identify application endpoints that may not be obvious from normal navigation.

## Sources
- links and forms
- JavaScript
- API specifications
- observed browser requests
- documented application routes
- authorized crawling

## Record
- path
- method
- parameters
- authentication state
- content type
- source

## Prioritize
Endpoints involving:
- account data
- object identifiers
- administrative actions
- file handling
- state changes
- APIs
- integrations

## Stopping Condition
Discovery must remain within authorized scope and reasonable request volume.
