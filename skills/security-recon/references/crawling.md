# Crawling

## Purpose
Discover reachable application functionality while preserving context.

## Collect
- links
- forms
- API calls
- parameters
- methods
- redirects
- JavaScript references
- authentication boundaries

## Method
Prefer normal, authorized application navigation and safe crawling.

## Evidence
Preserve the URL, method, source page, parameter names, and authentication context.

## Hunting Value
Use crawl results to identify authentication, authorization, API, injection, client-side, file, and workflow surfaces.

## Stopping Condition
Respect scope, rate limits, robots or program restrictions where applicable, and avoid unnecessary load.
