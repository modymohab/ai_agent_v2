# Security Research Knowledge Base

This repository is the persistent knowledge base for my security research.

It is designed to support:

- PortSwigger labs
- Bug bounty research
- CTF learning
- Reconnaissance
- Web application security
- API security
- Vulnerability research
- Security methodology

## Core Principle

Knowledge is not proof.

Always use:

Knowledge
→ Hypothesis
→ Current Evidence
→ Controlled Test
→ Verification
→ Conclusion

Stored knowledge helps generate hypotheses.

Current target evidence determines conclusions.

## Learning Loop

Research
→ Observe
→ Hypothesize
→ Test
→ Verify
→ Document
→ Generalize
→ Update Methodology

## Repository Layers

### methodology/

General reusable security knowledge.

### knowledge/

Specific labs, writeups, and real-world research.

### templates/

Structures for documenting research.

### index/

Navigation and retrieval.

### wordlists/

Wordlist organization and references used by security tooling.

## Important Rule

Specific research belongs in knowledge/.

General reusable lessons belong in methodology/.

Do not duplicate the same information unnecessarily.
